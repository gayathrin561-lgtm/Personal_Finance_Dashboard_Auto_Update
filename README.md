Personal Finance Dashboard Auto Update

Project Overview

Personal Finance Dashboard Auto Update is an automation project developed using n8n, Google Sheets, and JavaScript.

The system automatically reads financial transactions, calculates total income, expenses, and savings, and updates a dashboard in Google Sheets.

Technologies Used

- n8n – Workflow automation
- Google Sheets – Data storage and dashboard
- JavaScript – Financial calculations
- GitHub – Project storage and version control

Features

- Automatic financial data processing
- Income and expense tracking
- Savings calculation
- Google Sheets dashboard updates
- Financial charts and visualization
- Scheduled workflow execution

Workflow

Schedule Trigger → Google Sheets → JavaScript Code → Google Sheets Dashboard

How It Works

1. The Schedule Trigger starts the workflow.
2. Google Sheets provides transaction records.
3. JavaScript calculates income, expenses, and savings.
4. n8n updates the dashboard summary.
5. Google Sheets charts display the results.

Project Status

Workflow created and tested using n8n and Google Sheets.
